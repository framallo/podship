  1. Export main (a0dc2b0)
  2. Run tests: server
  3. Run tests: server-integration
  4. Run tests: app
  5. Build Flutter web: app
  6. Build Flutter web: admin
  7. Select files and write release
  8. Prepare caza-vps:/srv/cazafacturas-serverpod
  9. Upload files
  10. Create release
  11. Build images on the server
  12. Back up the database before the switch
  13. Switch to the new release
  14. Health check
  15. Mark healthy and keep 5 releases
The app restarts on the new release. If the health check fails, podship switches back on its own.
