Ubuntu 24.04, x86_64 · podship folders missing
podship isn't set up on shop-vps. Docker is missing and /srv/podship doesn't exist.

Bootstrap shop-vps

Installs Docker, compose, age, zstd, the firewall rules and podship's folders. Safe to run again.

  1. Check the OS (Debian or Ubuntu)
  2. Install Docker Engine and the compose plugin
  3. Install age, zstd, curl and rsync
  4. Apply firewall rules (allow 22; 80 and 443 only for Caddy)
  5. Create /srv/podship with lib, etc and registry.yaml
This runs to the end even if you close the console.
